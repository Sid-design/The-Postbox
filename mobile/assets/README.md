# App Assets for TestFlight & App Store

## Required Assets

### Icons
- [ ] `icon.png` - 1024x1024px (App Store icon)
- [ ] `icon-ios-foreground.png` - iOS adaptive icon foreground
- [ ] `icon-ios-background.png` - iOS adaptive icon background
- [ ] `notification-icon.png` - 48x48px (Push notification icon)

### Screenshots (Required for App Store)
- [ ] iPhone 6.7" (1290x2796px) - 3-5 screenshots
- [ ] iPhone 6.5" (1242x2688px) - 3-5 screenshots
- [ ] iPad Pro 12.9" (2048x2732px) - 1-2 screenshots

### Other
- [ ] `notification-sound.wav` - Custom notification sound (optional)

## Asset Generation Tools

### Online Tools:
- [App Icon Generator](https://appicon.co/) - Generate all icon sizes
- [Screenshot Mockup Tools](https://mockuphone.com/) - Create app screenshots

### Design Guidelines:
- **App Icon**: Clean, recognizable, follows iOS design principles
- **Screenshots**: Show app functionality, clean backgrounds
- **Colors**: Use your brand colors (#4A90E2 primary)
